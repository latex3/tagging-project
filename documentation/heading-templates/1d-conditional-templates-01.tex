\section{The declarations for conditional layout}

This section heading still has its normal layout.
But from now on we will apply the following declarations:
\begin{verbatim}[\small]
\DeclareInstanceCopy{heading}{section:recto}{section} % make copy
\EditInstance{heading}{section:recto}                 % edit it
   {heading-decls=\sffamily\bfseries\Large\raggedleft,
    headformat-instance=section:recto}
\DeclareInstance{headformat}{section:recto}{hang} % declare head-format
   {right-margin=-1cm}                            % instance used above

\DeclareInstanceCopy{heading}{section::unnumbered}{section}
\EditInstance{heading}{section::unnumbered}
  {title-decls=\ttfamily\centering}
\end{verbatim}

\DeclareInstanceCopy{heading}{section:recto}{section}
\EditInstance{heading}{section:recto}
   {heading-decls=\sffamily\bfseries\Large\raggedleft,
    headformat-instance=section:recto}
\DeclareInstance{headformat}{section:recto}{hang}
   {right-margin=-1cm}

\DeclareInstanceCopy{heading}{section::unnumbered}{section}
\EditInstance{heading}{section::unnumbered}
  {title-decls=\ttfamily\centering}


\section{A section heading}             

\emph{On a recto page we now get our \texttt{section:recto} layout which
shifts the heading into the outside margin and applies a different
font.}
